# SMLP - Sistem Manajemen Loyalitas Pelanggan

Back-End API Services untuk aplikasi Sistem Manajemen Loyalitas Pelanggan (SMLP).

## Tentang Aplikasi

SMLP adalah platform CRM dan loyalty management untuk Coffee Shop, yang memungkinkan pengelolaan:
- **Pelanggan**: Registrasi, profil, segmentasi, dan tier membership
- **Transaksi**: Pencatatan transaksi dan perhitungan poin otomatis
- **Reward**: Katalog reward, penukaran poin, dan riwayat redeem
- **Analytics**: Dashboard, customer insights, RFM analysis, dan laporan

## Aturan Poin

- Rp 10.000 = 1 poin (aturan dasar)
- Multiplier berdasarkan tier member
